## Local preview

Run `python3 -m http.server 8000` from the repository and open `http://localhost:8000`.

No installation or build step is required. The root contains the website; `assets/` contains artwork and motion; `downloads/` contains supporting deliverables.

## Project context

Self-initiated fictional concept work created with AI assistance, not paid client engagements. Audience and testing plans are hypotheses; no measured campaign results are claimed. The storefront uses a demo cart without payment processing. Packaging artwork is illustrative, not production-ready dielines.
